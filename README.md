Mini-Market Management System

A desktop application developed using C# and .NET Framework for mini-market management.

Technologies

- C#
- .NET Framework
- Windows Forms (WinForms)
- SQL Server

Features

- Product management
- Inventory management
- Sales management


Requirements

- Visual Studio
- The appropriate .NET Framework Developer Pack
- SQL Server

How to Run

1. Clone or download this repository.
2. Open "MiniMarketSystem.sln" in Visual Studio.
3. Configure the database connection
4. Build and run the project.
